# Vector Tutor — 45 Second Pitch

Learning AI is not difficult because students lack answers. It is difficult because they often don't know what to learn next.

Vector Tutor is a personalised AI tutor that turns a generic chatbot into an adaptive learning partner.

A learner selects their level, asks a question, gets a level-appropriate explanation, and immediately practises it with an AI-generated quiz. The system diagnoses weak concepts from quiz performance and recommends the next learning action.

Our core loop is simple:

**Learn → Practice → Diagnose → Adapt → Improve**

The result is not just an AI that answers questions, but an AI that helps the learner make measurable progress.
